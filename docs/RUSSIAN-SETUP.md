# Русская мультяшная веб-студия на базе OpenReels

Эта настройка добавляет творческий профиль для русскоязычных мультяшных объясняющих роликов. Она не меняет ядро OpenReels и не обещает идеальную идентичность персонажей: для этого нужна поддержка reference images на стороне выбранного генератора.

## 1. Запуск веб-версии

Требования проекта: Docker и Docker Compose. В корне репозитория:

```bash
cp .env.example .env
```

Добавьте ключи в локальный `.env` (не коммитьте его в GitHub). Для одного Google-стека достаточно `GOOGLE_API_KEY`; по README он может обслуживать LLM, изображения, TTS, видео и музыку, если эти функции доступны вашему аккаунту и региону. Альтернативно настройте отдельные провайдеры согласно `.env.example`.

Запуск:

```bash
docker compose up --build
```

Откройте http://localhost:3000. API и worker запускаются отдельными контейнерами, Redis используется для очередей.

## 2. Профиль мультяшного ролика

Творческий бриф находится в `examples/russian-cartoon-explainer.md`. Он задаёт:
- естественную русскую речь и русские экранные подписи;
- 2D мультяшную инфографику, единый контур и палитру;
- правила повторения внешности персонажа между сценами;
- мобильные субтитры, понятные переходы и финальное резюме.

Для CLI-генерации из корня проекта:

```bash
pnpm start "Почему меняется климат и что это значит для города" --provider google --direction examples/russian-cartoon-explainer.md --platform tiktok
```

Для короткого вертикального ролика можно выбрать `--platform tiktok` или `--platform instagram`. Доступные визуальные архетипы перечислены в README; для более иллюстративной подачи попробуйте `bold_illustration` или `comic_book`.

## 3. Русская озвучка

Выберите TTS-провайдера в настройках генерации веб-интерфейса или через поддерживаемый параметр CLI `--tts-provider`. В README перечислены Gemini TTS, OpenAI TTS, ElevenLabs, Inworld и Kokoro. Перед массовой генерацией сделайте короткий тест и проверьте произношение имён, чисел и сокращений. Наличие русского голоса зависит от конкретного провайдера и выбранного голоса.

## 4. Безопасность ключей и публикация

- Храните API-ключи только в `.env` или в секретах хостинга.
- Не добавляйте ключи в коммиты, issue, логи и сообщения чата.
- Для публичного сервера настройте HTTPS, авторизацию, ограничение запросов, резервное копирование каталога jobs и защищённое хранилище результатов.
- Не публикуйте порт API напрямую без reverse proxy и контроля доступа.
- Генерация видео и рендер могут иметь заметную стоимость; сначала используйте короткий тест и проверяйте оценку расходов.

## Ограничения текущей настройки

Этот коммит добавляет русскоязычный творческий профиль и инструкцию запуска. Он не включает в себя ваши API-ключи, не разворачивает сайт в облаке и не добавляет автоматическую оплату/провайдеров. Стабильность одного и того же персонажа зависит от выбранного image/video API; для production-уровня потребуется отдельная доработка reference-image workflow и проверка каждого кадра.
