# Как убрать лимит генерации: честная техническая схема

## Вывод

Нельзя обещать безлимитную генерацию видео бесплатно, если у пользователя нет собственного GPU/сервера. Генерация видео требует дорогого GPU-времени. Любой бесплатный облачный GPU ограничивает квоту, длительность сессии, очередь или доступность.

Можно убрать **лимит OpenReels** (не ограничивать число задач, длительность очереди и число повторов на уровне приложения), но нельзя убрать лимиты вычислительного провайдера.

## Проверенные варианты

| Вариант | Бесплатный ресурс | Ограничение | Подходит для постоянного backend |
|---|---|---|---|
| Hugging Face ZeroGPU | Общая GPU-инфраструктура | 5 GPU-минут в сутки для бесплатного аккаунта; очередь | Нет |
| Kaggle Notebooks | Бесплатный GPU | Около 30 GPU-часов в неделю; сессии ограничены по времени и доступности | Нет, только ручной/периодический запуск |
| Google Colab Free | Иногда доступный GPU | Доступ динамический; сессии до 12 часов, отключения и квоты | Нет |
| Собственный ComfyUI + LTX | GPU пользователя/арендованный сервер | Нет квоты OpenReels; ограничение только железом и электричеством/ценой | Да |

Источники и текущие правила могут меняться: Hugging Face ZeroGPU docs, Kaggle GPU usage docs, Google Colab FAQ.

## Рекомендуемое решение для OpenReels

1. **Убрать искусственные лимиты приложения:** не ограничивать число поставленных в очередь задач, длину очереди и число повторных попыток; добавить паузу/возобновление, сохранение прогресса и повтор после временной ошибки.
2. **Сделать провайдеры взаимозаменяемыми:** основной self-hosted ComfyUI/LTX, а бесплатные публичные демо — только как ручной/экспериментальный вариант, не как гарантированный API.
3. **Добавить Kaggle как опциональный пакетный исполнитель**, а не обещать постоянный сервер: пользователь запускает notebook, он обрабатывает очередь, сохраняет MP4 в подключённое хранилище; после завершения сессии обработка останавливается до следующего запуска.
4. **Не обходить квоты:** не создавать аккаунты-фермы, не ротировать чужие токены и не проксировать публичные Spaces в обход правил. Это нестабильно и может нарушать условия сервисов.
5. **Сохранить бесплатный режим телефона:** телефон остаётся пультом управления; тяжёлая генерация выполняется в облачном ноутбуке или на отдельном компьютере. Один только GitHub Pages не может выполнять генерацию.

## Что означает «без лимита» в интерфейсе

OpenReels может показывать режим «Очередь без лимита приложения»: можно добавлять сколько угодно задач, но выполнение зависит от доступности выбранного GPU-провайдера. Интерфейс обязан показывать квоту/статус провайдера и не называть этот режим безлимитным облачным GPU.

## Важное ограничение

Kaggle/Colab — не надёжный круглосуточный API-хостинг. Их бесплатные GPU-сессии могут завершаться, а адреса временных сред меняться. Нельзя безопасно обещать автоматическую отправку промта с телефона и возврат MP4 24/7 на одной бесплатной учётной записи. Для такого режима нужен собственный постоянно доступный сервер/GPU или оплачиваемая инфраструктура.
